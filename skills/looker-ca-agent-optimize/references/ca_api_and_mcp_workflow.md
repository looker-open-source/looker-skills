## 2. Step 6: Apply Approved Changes (Atomic Backup Verification & Agent Update — Lines 13-20)

Execute Step 6 **only after user approval at Gate #2** (or immediately if the user's prompt explicitly requested applying the changes without waiting, and `can.update == true`):
- **LookML-Defined Agents (`"is_lookml": true`):** `PATCH /api/4.0/agents/{id}` is rejected or overwritten on LookML agents. Skip `update_agent`. If `has_develop_permission == true`, resolve the project-relative `.lkml` path from `lookml_edit_uri` + `get_project_files` and apply the approved agent instructions/golden queries in `dev_mode` (or export via `looker-cli api conversationalanalytics agent_lookml "<id>"`). **If `has_develop_permission == false`, include the complete upgraded LookML agent instruction/golden-query block inside the Gate #2 Developer Handoff Note so it is never dropped.**
1. **Verify Backup & Validate Root-Level YAML In-Memory (`0.1s`):** Confirm `/tmp/ca_agent_backup_<id>_<ts>.json` exists (writing it if not yet saved), replace any `&amp;`/`&lt;`/`&gt;` with natural `&`/`<`/`>`, assert `len(instructions) <= 4800`, verify all 4 root-level YAML keys (`role_and_tone:`, `explore_and_filtering_rules:`, `semantic_and_execution_rules:`, `presentation_and_analysis_rules:`) at column 0 and zero `	` tabs, and run `yaml.safe_load(instructions)` when `PyYAML` is installed.
2. **Sync Approved Golden Queries Concurrently & Update Agent:** Use `concurrent.futures.ThreadPoolExecutor(max_workers=5)` inside one atomic `python3 - <<'PY'` script to update modified Golden Queries in place via `update_golden_query "<gq_id>" -` (`{"questions": ["<single_question>"], "answer": "https://<host>/x/<slug>"}`), register net-new ones via `create_golden_query -` (`< 20` total cap), and delete obsolete ones via `delete_golden_query "<old_id>"`. Then call `update_agent "<agent_id>" -` preserving `"name"`, `"description"`, `"category"` (`"dashboard"` and `"<instance_origin>-<dashboard_id>"` on Dashboard Agents), and `"sources"` while updating approved `"context": {"instructions": ...}`, `"code_interpreter"`, and `"golden_query_ids"` (omitting `"golden_query_ids"` on Dashboard Agents). Confirm the applied changes, agent link, and rollback backup path.

## 3. `Optimize` (`Advanced` / `Hard`) Mode: Eval Suite Ingestion, `[TMP-SXS-EVAL]` Draft Clone & Two-Step Cleanup *(Step 4 — Lines 22-31)*

Execute Step 4 **only in `Optimize` (`Advanced` / `Hard`) mode**:
1. **Ingest Structured Eval Suite (`3-5` Questions Recommended) or Auto-Generate:**
   - Support `(question, ground_truth, issue_description)` from: **(a) Inline Text / Markdown Table**, **(b) Local `.csv` / `.tsv` File** via `csv.DictReader` (matching `question`, `ground_truth`/`expected_answer`, `issue_description`/`notes` case-insensitively), or **(c) Google Sheets URL / ID** via Drive/Sheets tools or CSV export.
   - If omitted, pull top failing/slow questions from Step 2 `system__activity.conversations_feedback` or auto-generate `3-4` realistic questions grounded in the Explore. Compare baseline and candidate answers against live Looker MCP `query` Ground Truth and use `issue_description` to target root-cause fixes.
2. **Run Baseline & Draft `[TMP-SXS-EVAL]` Clone Traces Without Publishing:**
   - For each question, run `create_conversation -` (`{"agent_id": "<id>", "name": "[TMP-SXS] Qn"}`) and `conversational_analytics_chat -` (`{"conversation_id": "<conv_id>", "user_message": "<question>"}`), recording directional latency (P50/P90), accuracy count (e.g., `4 of 5`), `systemMessage.text` (`textType == "THOUGHT"`), `systemMessage.data.generatedLookerQuery`, and `python_and_chart_agent` overhead.
   - Test the draft config **without modifying the live agent** by creating an isolated clone via `create_agent -` (`"name": "[TMP-SXS-EVAL] <Original Name>"`, `"description"`, `"sources"`, candidate `"context"`, `"code_interpreter"`, and fresh temporary Golden Query IDs via `create_golden_query -`—never reuse live `golden_query_ids`; for Dashboard Agents, test the clone as a temporary conversation-category clone with identical tile `"sources"` and `"context"` so `create_conversation` never 404s).
   - Run **Round 1** SxS self-check (if target metric improves with 0 regressions, proceed to Step 5; otherwise revise once using Round 1 traces and run **Round 2 [final]**), then immediately purge all temporary conversations, the `[TMP-SXS-EVAL]` agent, and temporary Golden Queries via **`update_* {"deleted": true}` followed by `delete_*`**.
